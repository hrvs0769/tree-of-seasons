## 1. 五个时间量

| 量 | 公式 | 含义 |
|---|---|---|
| `t` | 当前 `storyTime` | 故事时间（秒）；`?t0=N` 可整体偏移；`?freeze` 钉死 |
| `g` | `growthAt(t)` | 生长进度 0..1，分段平滑；**120s 后饱和为 1** |
| `p` | `storySeason(t)` 取小数部分 | 一年进度 0..1，一年 = `SEASON_SECONDS * 4 = 80s` |
| `yearIndex` | `storyYear(t)` | 第几年：t<120 为 1；t≥180 为 2 |
| `rootAge` | `g + 0.30 * smoothstep(120, 235, t)` | **第二轮新增**：根系年龄，解开「g 在 120s 饱和、第 2 年根完全静止」的死锁；根显隐/根毛/水层/深潜镜头都用它 |

另有三个派生权重：`waterReveal = smoothstep(0.98, 1.16, rootAge)`（水层亮度）、`deepReveal = quartetShooting ? 0 : smoothstep(205, 255, t) * smoothstep(0.90, 1.45, aspect)`（相机下沿）、`closeBoost = 1 - smoothstep(1.0, 4.2, closeFrame.viewH)`（微距补光）。

### 1.1 `growthAt(t)`（未改动）

源码：`src/main.js` 的 `GROW_KEYS` 与 `growthAt()`。

```js
[
  [0, 0.000],
  [16, 0.004],   // 种子吸水
  [32, 0.020],   // 破壳
  [56, 0.060],   // 主根向下、主干开始
  [76, 0.140],   // 破土、子叶
  [94, 0.280],   // 幼苗

  [116, 0.750],  // 树冠展开

```

每段内部用 `smoothstep(0, 1, u)` 平滑连接。这样前 76 秒（种子/春雨/扎根/破土）占足时间，后面抽枝成树加速。

### 1.2 `storySeason(t)` / `storyYear(t)`

```js
if (t < GROW_END) return 0.02 + (0.25 - 0.02) * (t / GROW_END);
return 0.25 + (t - GROW_END) / (SEASON_SECONDS * 4);
```

- 生长阶段（0–120s）视作春天，`p` 从 0.02 缓慢到 0.25（夏初）。
- 120s 后从夏初开始正常四季循环；每季 `SEASON_SECONDS = 20s`，一年 80s。
- `storyYear(t)`：`t<120` 为第 1 年；`1 + Math.floor((t-120)/80 + 0.25)`，第 2 年从 **180s** 开始（p 回到 0）。
- `samplePalette(p)` 的过渡窗口本轮由 `smoothstep(0.55, 0.95, frac)` 改为 **`smoothstep(0.86, 1.0, frac)`**：每季前 17.2s 保持本季纯色，只在最后 2.8s 过渡到下一季，季末配色与 HUD 标签对齐（旧版会让 t=139–140 已是纯秋色却写「夏」、t=179 起纯春绿却仍下雪）。

## 5. 镜头脚本

源码：`CAM_KEYS` + `cameraFrameAt(t)`。关键帧**未改动**：

```js
[
  [0, 0.10, 0.9],
  [18, 0.08, 1.1],
  [32, 0.00, 1.3],
  [42, -0.55, 2.7],
  [56, -0.70, 3.1],
  [70, 0.00, 1.8],
  [76, 0.35, 2.2],
  [94, 1.20, 3.8],
  [108, 2.20, 5.2],
  [120, 3.00, 10.8],
]
```

每项 `[t, targetY, viewH]`；`fitR = viewH / (2 * tan(fov/2))`。

- 0–32s：种子微距；32–56s：根系剖面；56–76s：破土/子叶；76–94s：幼苗；94–108s：小树；108–120s：后拉到全树。
- **`t >= 120` 不再一帧硬切**：`cameraFrameAt()` 返回 `null` 后，用 `last = cameraFrameAt(119.999)` 与 `b = smoothstep(120, 130, t)`，把 `targetY` 和 `viewH` 从脚本末帧平滑过渡到自动取景值（120–130s）。
- 自动取景：`topY = max(0.9, crownTop + 0.52)`，`BOTTOM_AUTO = -0.62 - 3.6*smoothstep(0, 0.34, g) - 6.35*deepReveal`，`autoTargetY = (topY + BOTTOM_AUTO)/2`，`autoViewH = topY - BOTTOM_AUTO`。
- `deepReveal = quartetShooting ? 0 : smoothstep(205, 255, t) * smoothstep(0.90, 1.45, aspectNow)`：只在最后两章渐进把下沿压到 `≈ -10.57`，露出 `WATER_TOP = -9.6` 的含水层；第 12 章（t=210）树仍占画面约 60%，不因深潜变小；竖屏靠 `aspectFix` 已能看到深剖面，不再额外拉远；**四季合影期间强制 0** 保证四张照片构图一致。
- `THETA_MIN/MAX = π/2 ± 0.36`（旧 ±0.62）：镜头自动环绕与拖拽的摆幅收窄，剖面地平线不再明显倾斜。
- `cam.target.x = 0.5*smoothstep(0.15, 0.70, g)`；`effR = max(1.35, fitR) * (cam.radius/12.5) * aspectFix`。
- `window.__classroom.seekForTest(t)` 会把 `cam.theta/radius/phi` 复位为 `1.46/12.5/1.46`，保证截图正面视角可复现。

## 6. 播放器和时间控制

源码：状态区（`CHAPTERS` 下方）与 `animate()` 开头。

- `storyTime` 是唯一时间基准；`playing` 为布尔。
- 播放时 `storyTime += realDt`（真实时间，限制最大 0.1s，避免切后台跳跃）。
- 到 `STORY_END` 自动 `playing=false`，不循环。
- `t = VIDEO ? videoT : (freezeOverride !== null ? freezeOverride : (FREEZE_T !== null ? FREEZE_T : storyTime))`。
- **`dt = VIDEO ? 1/60 : ((playing && FREEZE_T === null && freezeOverride === null) ? Math.min(0.05, Math.max(0.0001, t - prevT)) : 0)`**：定帧 / 暂停 / 四季合影时粒子彻底静止。
- `?freeze`：`t = FREEZE_T`，`playing=false`，播放器隐藏；树种子固定为 `20240601`。
- `?video`：`t = videoT`，由外部脚本喂入。
- `?t0=N`：初始 `storyTime=N`，默认继续播放；会自动跳过开场页。
- `?class`：进入课堂模式；默认开启「每章结束自动暂停」，停在 `CHAPTERS[i].end`。
- 定帧 / 暂停且未播放时，`staticKey`（`t` + 相机三参数 + 找一找状态）不变则不重绘，无头截图不会每帧跑 400+ draw call。

进度条和章节刻度：`#timeline` 的 `min/max` 由 `STORY_END` 设置；`#marks` 由 `CHAPTERS.start` 自动生成；`updateChapterUI(t)` 更新章节 DOM 与大字幕；`syncPlayer()` 更新 `#timecode`、滑块、进度色、播放图标。

## 8. 已知教训

- 曾出现「第 2 章春雨滋润开始时雨已经下完」：雨窗写成 4–15s，而章节从 16s 才开始。**章节时间和视觉窗口必须来自同一张表**。
- 曾出现「第 3 章向下扎根时侧根还没出现」：根系的 `dur` 与 `GROW_KEYS` 不同步。改根参数后务必看第 3 章实际截图。
- 曾出现「根在第 2 年完全静止」：`g` 在 120s 饱和，所有根的 `g1` 都早于 0.25。第二轮用 `rootAge` 单独给根系一条继续增长的时间轴。
- 曾出现「冬章末尾绿地下雪 / 夏章末尾是秋色」：`samplePalette` 在季内 55% 就混入下一季且季末 5% 已是下一季纯色。改为 `0.86–1.0` 后，配色与 HUD 标签同步。
- 曾出现「花未开先落瓣、雪中飘桃花」：`petalRate` 用 `p>0.88`（深冬）。花瓣窗口必须与花期同源。
- 曾出现「落叶毯比树叶还早出现」：毯子从 p=0.50 起、树冠叶从 p=0.58 才落。现在两者都从 p≈0.58 起且连续淡入。
- `storySeason` 的 `p` 是「故事季节」，不是自然季节；生长阶段故意固定在春季，不要用真实年份公式替代。
