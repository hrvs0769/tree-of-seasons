# 一棵树的四季

纯代码生成的 3D 树木生命周期演示（Three.js）。剖面视角：地上看发芽长叶，地下看生根。配课堂旁白、暂停和可拖动进度条，全程不加载任何外部素材。

## 直接打开

双击 `index.html` 即可（已打包为普通脚本，无需本地服务器、无需联网）。

## 看什么

1. **种子入土（0–16 秒）**：种子半埋在土里，镜头贴近观察
2. **春雨滋润（16–32 秒）**：种皮吸水变大，从中间裂开
3. **向下扎根（32–56 秒）**：主根向下钻，侧根向四周铺开，根在剖面前薄层里清晰可见
4. **破土发芽（56–76 秒）**：嫩芽顶开种壳，两片子叶展开
5. **幼苗初长（76–94 秒）**：茎秆变粗，真叶出现
6. **小树成形（94–108 秒）**：枝丫一层层向外伸展
7. **长成大树（108–120 秒）**：树冠展开，成为一棵大树
8. **四季轮回（120 秒以后）**：
   - 第一年夏、秋、冬
   - 第二年春、夏、秋（结果）、冬
   - 秋天叶子先变红金，再一片片落下；落在地上的叶子会逐渐变暗、下沉、腐烂成泥土的养分，而不是被“收回去”

一轮故事全长约 4 分 20 秒；到结尾会自动停下，不会无限循环。

## 交互

- **左侧讲解栏**：显示当前章节标题和可朗读的旁白正文
- **播放 / 暂停**：底部播放器左侧按钮，或按 `空格`
- **拖动进度条**：可以停在任意时刻，也可以快速跳到想看的位置
- **前后 5 秒**：← / → 方向键
- **重播**：底部播放器里的「↻ 重播」从头开始
- **再种一棵**：底部「再种一棵」按钮或按 `R`，随机长出一棵全新的树
- **视角**：拖动环顾，滚轮 / 双指缩放
- 底部有章节刻度，季节、旁白和章节标题都会跟着时间变化

## 课堂旁白

桌面端采用「左侧讲解栏 + 右侧 3D 舞台 + 底部播放条」的课堂布局：讲解文字独占左侧深色栏，不会压住树冠、树干或根部。旁白按 14 个章节显示，可以直接照着念给小朋友听：

- 种子入土 → 春雨滋润 → 向下扎根 → 破土发芽 → 幼苗初长 → 小树成形 → 长成大树
- 第一年夏 / 秋 / 冬
- 第二年春 / 夏 / 秋（结果）/ 冬

旁白文字、章节编号和标题都会随进度条实时更新。

## 技术说明

- `src/main.js` — 全部场景逻辑：递归树/根系生成、生长时间轴、四季调色板、实例化树叶/草/花/雪、程序化天空与远山、土壤剖面、HUD 和播放器
- `lib/three.module.min.js` — Three.js（取自本机 solar-system 项目的依赖）
- `app.js` — esbuild 打包产物：
  `esbuild src/main.js --bundle --format=iife --minify --alias:three=./lib/three.module.min.js --outfile=app.js`
- 场景结构：半圆岛（z ≤ 0）＋ 正对镜头的土壤断面（表土、心土、底土分层，3D 团粒和石子）＋ 断面前薄层里的根系
- 生长时间轴：`GROW_KEYS` 控制 0–120 秒的非线性生长；季节从长成后开始每季 20 秒
- 镜头：种子微距 → 根系剖面 → 破土 → 幼苗 → 后拉看全树；长成后自动框住整棵树
- 调试：URL 加 `?debug` 看时间轴日志，`?t0=52` 直接从第 52 秒开始
- 定帧：`?t0=34&freeze` 把时间钉死在第 34 秒不放，画面完全静止 —— 截图对比用
- 视觉迭代：`./tools/shoot.sh rN` 一轮出 7 张（桌面 7 个时间点 + 手机 1 张）拼图 `shots/rN/sheet.png`，评审记录见 `ITERATIONS.md`
