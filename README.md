# 一棵树的四季

纯代码生成的 3D 树木生命周期演示（Three.js）。剖面视角：地上看发芽长叶，地下看生根。

## 直接打开

双击 `index.html` 即可（已打包为普通脚本，无需本地服务器、无需联网）。

## 看什么

1. **种子下地**：一颗种子埋在土里（剖面看得到）
2. **先生根**：主根往下钻，左右分出不规则侧根，铺满土层
3. **再发芽**：嫩芽破土，两片子叶展开
4. **长成树**：树干、主枝、侧枝、细枝一层层长出去，叶子跟着冒
5. **四季循环**：春（花芽）→ 夏（满树）→ 秋（叶变红、飘落）→ 冬（下雪、光秃）→ 再来一年

全程约 30 秒长成大树（刚好长到盛夏），之后每年约 88 秒循环四季。

## 交互

- 拖动：环顾（镜头限制在剖切面前方的弧形范围内，保证随时能看到地下）
- 滚轮 / 双指：缩放
- 「再种一棵」按钮或按 `R`：随机长出一棵全新的树（根系也会重新长）

## 技术说明

- `src/main.js` — 全部场景逻辑：递归树/根系生成、四季调色板插值、实例化树叶、雪/花瓣/落叶粒子、土壤剖面
- `lib/three.module.min.js` — Three.js（取自本机 solar-system 项目的依赖）
- `app.js` — esbuild 打包产物：
  `esbuild src/main.js --bundle --format=iife --minify --alias:three=./lib/three.module.min.js --outfile=app.js`
- 场景结构：半圆岛（z ≤ 0）＋ 正对镜头的土壤断面（表土 3.2 米有纹理细节，下面是深土）＋ 断面前薄层里的根系
- 调试：URL 加 `?debug` 看时间轴日志，`?t0=52` 直接从第 52 秒开始
- 定帧：`?t0=34&freeze` 把时间钉死在第 34 秒不放，画面完全静止 —— 截图对比用
- 视觉迭代：`./tools/shoot.sh rN` 一轮出 6 张桌面 + 1 张手机拼图（`shots/rN/sheet.png`），评审记录见 `ITERATIONS.md`
