# 一棵树的四季

纯代码生成的 3D 树木生命周期演示（Three.js）。剖面视角：地上看发芽长叶，地下看生根。电影感黄昏光、流动云层、远山晨雾、四季粒子，全程不加载任何外部素材。

## 直接打开

双击 `index.html` 即可（已打包为普通脚本，无需本地服务器、无需联网）。

## 看什么

1. **种子下地**：一颗种子半埋在土里（剖面看得到），根往下钻
2. **先生根**：主根往下钻，左右分出不规则侧根、板根，铺满土层
3. **再发芽**：嫩芽破土，两片子叶展开
4. **长成树**：树干、主枝、侧枝、细枝一层层长出去，叶子跟着冒；春天先开一树白花
5. **四季循环**：
   - 春：新芽、野花、花瓣雨
   - 夏：满树浓绿、逆光浮尘
   - 秋：叶变红金、落叶铺地、第二年结果
   - 冬：枝头积雪、雪粒子、白茫茫的草土断面
6. **电影感镜头**：低机位金色逆光、太阳光芒、三层远山、草浪和晨雾

全程约 30 秒长成大树（刚好长到盛夏），之后每年约 88 秒循环四季。

## 交互

- 拖动：环顾（镜头限制在剖切面前方的弧形范围内，保证随时能看到地下）
- 滚轮 / 双指：缩放
- 「再种一棵」按钮或按 `R`：随机长出一棵全新的树（根系也会重新长）

## 技术说明

- `src/main.js` — 全部场景逻辑：递归树/根系生成、四季调色板插值、实例化树叶/草/花/雪、程序化天空与远山、土壤剖面、HUD
- `lib/three.module.min.js` — Three.js（取自本机 solar-system 项目的依赖）
- `app.js` — esbuild 打包产物：
  `esbuild src/main.js --bundle --format=iife --minify --alias:three=./lib/three.module.min.js --outfile=app.js`
- 场景结构：半圆岛（z ≤ 0）＋ 正对镜头的土壤断面（表土、心土、底土分层，3D 团粒和石子）＋ 断面前薄层里的根系
- 光照：ACES 色调映射，低角度金色逆光 + 正面补光 + 剖面补光；天空是程序化 shader（太阳盘、暖晕、两层流动云）
- 调试：URL 加 `?debug` 看时间轴日志，`?t0=52` 直接从第 52 秒开始
- 定帧：`?t0=34&freeze` 把时间钉死在第 34 秒不放，画面完全静止 —— 截图对比用
- 视觉迭代：`./tools/shoot.sh rN` 一轮出 7 张（桌面 6 个时间点 + 手机 1 张）拼图 `shots/rN/sheet.png`，评审记录见 `ITERATIONS.md`
