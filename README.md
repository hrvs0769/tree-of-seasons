# 一棵树的四季

纯代码生成的 3D 树木生命周期演示（Three.js）。剖面视角：地上看发芽长叶，地下看生根、一直扎到含水层。配课堂旁白、暂停和可拖动进度条，全程不加载任何外部素材。

> 最后更新：2026-11-06 · 对应代码：`a99c037`（第二轮优化 · 确定性基线 · 深根水层 · 鸟虫树荫 · 文案对齐）

线上课堂模式直达：https://hrvs0769.github.io/tree-of-seasons/?class

视觉审查工具：`./tools/visual-audit.sh audit-rN`（默认快速 8 张；`AUDIT_FULL=1` 全量 24 张）

## 本轮新增（2026-11-06 · 第二轮优化）

- **截图可复现**：`?t0=N&freeze`、`?class`、`?stage`、`?video` 都使用固定树种子；两次独立加载同一时间点逐像素一致，截图对比和视觉审查终于可信。
- **第一章不再是一块黑**：土壤剖面重绘成 6 层（含毛管湿润带、含水饱和带、母质），表土提亮，近景有草根、土粒、孔隙，`?t0=6` 下半屏亮度实测由 16.9 提升到 85.7。
- **根真的扎到水层**：剖面加深到 12 单位，新增第 2 年深扎续根与贴近潜水面的吸水须根，水面反光、波纹、气泡、根尖吸水光点随根到达而亮起；最后两章镜头会渐进拉远露出含水层。
- **天空有生机**：云层真的出现了（原来被 shader 阈值关掉），并新增远处偶尔飞过的鸟群、栖息的小鸟、蝴蝶/蜜蜂/瓢虫、飘过地面的云影、春末飞絮、树荫与光斑。
- **文字和画面对齐**：裂壳提前到第 2 章、子叶留在近地面、春花只在第二年且放大成簇、果实青→熟变色并不再穿地、落叶毯延后并连续淡入、雪帽雪提前且放大、雨窗重排、结尾拨回「春 · 万物发芽 · 新的轮回」并冒出一株新芽。
- **找一找新增「小鸟 / 昆虫」部位**，点中昆虫会提示「找到啦！这是昆虫」。

## 看什么

1. **种子入土（0–16 秒）**：种子半埋在松软的表土里，镜头微距，能看清草根、土粒与孔隙
2. **春雨滋润（16–32 秒）**：春雨落下，种皮吸水变大，**当章就能看到中间裂开一条缝**
3. **向下扎根（32–56 秒）**：主根向下钻，侧根和板根向四周铺开；根系现在有前后体积，不是一张纸片
4. **破土发芽（56–76 秒）**：嫩芽顶着种壳钻出地面，两片子叶在近地面展开
5. **幼苗初长（76–94 秒）**：茎秆变粗，真叶出现，子叶逐渐枯萎
6. **小树成形（94–108 秒）**：枝丫一层层向外伸展，96–106 秒有一阵雨
7. **长成大树（108–120 秒）**：树冠展开，成为一棵大树
8. **四季轮回（120 秒以后）**：
   - 第一年夏（树荫与光斑）、秋（叶落、地面落叶毯）、冬（下雪、枝头积雪）
   - 第二年春（花簇、蜜蜂、飞絮）、夏（飞鸟、蝴蝶、蜜蜂、瓢虫、树荫）、秋（青果转红、熟果落地、滚出种子）、冬（深根抵达含水层，结尾冒出新芽）
   - 秋天叶子先变红金，再一片片落下；落叶毯连续铺开、变暗、下沉、腐烂成泥土的养分，而不是被「收回去」

一轮故事全长约 4 分 20 秒；到结尾会自动停下，不会无限循环。

## 交互

- **左侧讲解栏**：显示当前章节标题和可朗读的旁白正文
- **播放 / 暂停**：底部播放器左侧按钮，或按 `空格`
- **拖动进度条**：可以停在任意时刻，也可以快速跳到想看的位置
- **前后 5 秒**：← / → 方向键
- **重播**：底部播放器里的「↻ 重播」从头开始
- **再种一棵**：底部「再种一棵」按钮或按 `R`，沿固定随机流长出一棵全新的树（普通观看模式）
- **视角**：拖动环顾，滚轮 / 双指缩放（左右摆幅收窄到 ±0.36 弧度，剖面地平线不再明显倾斜）
- 底部有章节刻度，季节、旁白和章节标题都会跟着时间变化

## 课堂模式（幼儿园课堂版）

打开页面后点「开始上课」，或直接访问 `index.html?class`，进入课堂模式：

- 自动全屏，隐藏所有小按钮和操作提示，只保留大画面、大字幕和三个大按钮
- 每章结束自动暂停，老师可以停下来提问、做动作，再点「下一章」
- 14 张章节卡片，点一下直接跳到任意一章
- 大字幕自动高亮关键词（种子、根、芽、叶、花、果、小鸟、昆虫、蜜蜂、蝴蝶、瓢虫），可开启“故事姐姐”朗读
- 点一下树上的部位，会出现「种子 / 根 / 树干 / 树枝 / 叶 / 花 / 果 / 雪 / 小鸟 / 昆虫」的认读卡片
- 「找一找」小游戏：按当前章节的**真实可见部位**依次出题（含鸟虫），不重复问同一个部位；显示「第几轮 · 第几个」，可点「下一个」继续
- 四季转盘（色环已校正 90°）+ 「四季合影」：把同一棵树的春夏秋冬放在一起对比
- 投影增亮、屏幕锁定（长按 2 秒解锁）、屏幕常亮
- 支持翻页笔：空格暂停，PageUp / PageDown 切换上一章 / 下一章

课堂模式键盘：`空格` 播放/暂停，`←` / `→` 前后 5 秒，`PageUp` / `PageDown` 切换章节，`F` 全屏，`C` 章节，`T` 教师提示，`Q` 四季合影，`P` 投影增亮，`L` 锁定，`R` 再种一棵，`M` 音乐。

> 课堂模式仍然通过 GitHub Pages 访问，不提供离线安装包。建议使用 Chrome / Edge；按 `Esc` 退出全屏，点右上角「退出」回到开始页。

## 课堂旁白

桌面端采用「左侧讲解栏 + 右侧 3D 舞台 + 底部播放条」的课堂布局：讲解文字独占左侧深色栏，不会压住树冠、树干或根部。旁白按 14 个章节显示，可以直接照着念给小朋友听：

- 种子入土 → 春雨滋润 → 向下扎根 → 破土发芽 → 幼苗初长 → 小树成形 → 长成大树
- 第一年夏 / 秋 / 冬
- 第二年春 / 夏 / 秋（结果）/ 冬

旁白文字、章节编号和标题都会随进度条实时更新。

## 技术说明

- `src/main.js` — 全部场景逻辑：递归树/根系生成、生长时间轴、四季调色板、实例化树叶/草/花/雪、程序化天空与远山、土壤剖面与地下水层、鸟虫与树荫、HUD 和播放器
- `lib/three.module.min.js` — Three.js（取自本机 solar-system 项目的依赖）
- `app.js` — esbuild 打包产物：
  `esbuild src/main.js --bundle --format=iife --minify --alias:three=./lib/three.module.min.js --outfile=app.js`
- 场景结构：半圆岛（z ≤ 0）＋ 正对镜头的土壤断面（6 层土壤、3D 团粒/石子/草根、地下水层）＋ 有体积的根系
- 生长时间轴：`GROW_KEYS` 控制 0–120 秒的非线性生长；季节从长成后开始每季 20 秒；根系另用 `rootAge` 在第 2 年继续深扎
- 镜头：种子微距 → 根系剖面 → 破土 → 幼苗 → 后拉看全树；t=120–130 平滑交接，最后两章渐进露出含水层
- 调试：URL 加 `?debug` 看时间轴日志，`?t0=52` 直接从第 52 秒开始
- 定帧：`?t0=34&freeze` 把时间钉死在第 34 秒不放，画面完全静止且每次加载一致 —— 截图对比用
- `?dbg` 暴露 `window.__renderer` 等探针；`window.__classroom.seekForTest(t)` 会复位 `cam.theta/radius/phi=1.46/12.5/1.46`，保证截图是正面视角
- 视觉迭代：`./tools/shoot.sh rN` 一轮出 **11 张桌面关键帧**（`6 / 20 / 44 / 66 / 100 / 128 / 170 / 190 / 210 / 230 / 250` 秒，覆盖春雨 / 根系 / 四季 / 鸟虫 / 果实 / 深根水层）+ 1 张手机 390×844（`190` 秒），拼成 `shots/rN/sheet.png`；`./tools/visual-audit.sh audit-rN` 出固定审查截图与评分骨架。评审记录见 `ITERATIONS.md`

## 背景音乐

网页配乐使用 Yoiyami 的《The Budding of Consciousness》，**CC0 1.0 公有领域**（可商用、可修改、可再分发、无需署名）。极简氛围钢琴，不抢课堂旁白。完整授权与溯源见 `assets/MUSIC-LICENSE.md`。

- `assets/tree-of-seasons-bgm-v3.mp3` — 网页成品（260 秒 / 约 119 kbps / 3.7 MB）：原曲 3:44 做 3 秒交叉淡化铺满 4:20，2 秒淡入、4 秒淡出，整体压低 4 dB
- `src/bgm.js` — 播放控制：跟随播放 / 暂停 / 进度跳转 / 重播，截图与导出视频模式自动静音。独立普通脚本，不参与打包，`app.js` 不用改
- 底部播放条的「♫ 音乐」开关或 `M` 键开关，旁边滑块调音量（默认 85%）；选择会记在本机
- 浏览器禁止无交互自动出声：若打开页面没声音，点一下「♫ 开启音乐」即可

> 早期尝试过纯代码合成配乐（`tools/make-web-bgm.js`、`tools/make-bgm-sampled.py`），音质不理想已弃用，仅作存档，网页不加载。根目录的 `tree-of-seasons-bgm.wav` 是给导出视频短片用的另一首 58 秒配乐，网页同样不加载。

换曲：把音频放进 `assets/`，改 `index.html` 里 `<audio id="bgm">` 的 `src`，同步更新 `assets/MUSIC-LICENSE.md`。播放同步由 `src/bgm.js` 跟随播放条自动完成，3D 代码不用改。
